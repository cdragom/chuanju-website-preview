# 川韵遗音 · 川剧文化网站预览

川剧文化主题的学生设计作品，共 16 个可交互页面。网站采用静态 HTML、CSS 与 JavaScript，无需安装或构建。

## 在线浏览

https://cdragom.github.io/chuanju-website-preview/

## 页面与交互

- 首页、川剧百科、沉浸体验、演出活动、文创商城、关于我们
- 登录、购票、初次来访、合作共创、个人中心、订单、确认订单、电子票、资料设置、到场指南
- 首页章节导航、分类与搜索、脸谱灵感卡、购物袋、演示选座购票、订单筛选、资料本地保存

## 本地预览

在此目录运行 `python3 -m http.server 8080`，访问 http://localhost:8080/。
